## Project Manager

### O que é?
O *project manager* foi um projeto desenvolvido no início da segunda semana do primeiro período da minha graduação, na disciplina de raciocínio computacional. O programa foi desenvolvido em Python ao longo de 8 semanas, com o objetivo de ser um gerenciador de projetos pessoais simples e intuitivo. Funciona como um programa CRUD completo.

### Como instalar e rodar?
Se você quer apenas rodar o programa sem precisar instalar o Python, siga estes passos:

1. Vá até a seção [Releases](Project_Manager) deste repositório.
2. Baixe o arquivo `main.exe` da versão mais recente.
3. Basta dar um clique duplo no arquivo para executar!

### Para desenvolvedores
Caso queira instalar o código fonte em conjunto, siga estes passos:

1. Baixe o arquivo **.zip**
2. Certifique-se de que você tem o Python instalado no seu computador
3. Localize o arquivo `main.py`
4. Abra na sua IDE, como VScode ou PyCharm
5. O script utiliza apenas bibliotecas standard que já vem instaladas com o Python, então não será necessária a instalação de bibliotecas via pip

### Linguagem utilizada
O programa foi totalmente desenvovlido em Python e a persistência dos dados é feita em um arquivo dados.json.
